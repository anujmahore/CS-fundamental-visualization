Binary Digit

What is a Bit?

Short for Binary Digit. It is the atomic unit of digital computation. Physically, computers don't have literal 1s and 0s—they have tiny microscopic MOSFET switches (transistors) holding an electric charge.

Formula: 2N where N = bits

Why only 0 and 1?

Analog voltages are noisy. Fluctuations in temperature and wire resistance make it hard to reliably detect 10 different voltages (like 0.1V, 0.2V, etc.).

Threshold 0 (OFF): < 0.4 Volts
Threshold 1 (ON): > 0.8 Volts

By setting a huge safety margin between HIGH and LOW, digital computers can run trillions of calculations without a single bit flipping by mistake.

Scale in Modern Hardware

A modern Apple M3 / AMD Ryzen / Intel Core CPU contains over 25 to 90 Billion transistors, each acting as one microscopic bit switch!

Why 8 bits specifically? Early computers had 4-bit, 6-bit, and 9-bit words. In the 1960s, IBM's System/360 standardized on 8 bits because it was just enough to encode upper and lowercase Roman letters, numbers 0-9, and punctuation in ASCII, while making binary arithmetic clean and powers-of-two friendly!
Natural Architecture Size

What is a "Word"?

While a Byte is universally 8 bits, a Word is NOT fixed across all computers. A "Word" is the natural chunk of data that a specific CPU architecture handles in a single operation, register, or bus transfer.

Core Concept

What does "32-bit" or "64-bit System" Actually Mean?

When an OS or processor is called "32-bit" or "64-bit", it refers to three tightly linked architectural pillars:

1. Internal Register Size

Registers are the ultra-fast storage buckets right inside the CPU core. A 64-bit CPU has 64-bit general-purpose registers (RAX, RBX, etc.), letting it crunch enormous 64-bit integers and double-precision floats in a single clock cycle.

32-bit: EAX (32b)
64-bit: RAX (64b)

2. Data Bus Width

Like widening a highway from 32 lanes to 64 lanes. The CPU can fetch 8 whole bytes from cache/RAM in one trip instead of only 4 bytes. Heavy workloads (3D rendering, video encoding, gaming) transfer twice as much raw data per bus tick.

Throughput: 2× data per bus cycle

3. Memory Address Space

Every byte in RAM needs a unique numerical street address. A 32-bit address bus can only create 232 distinct addresses = 4,294,967,296 bytes = 4 GB. 64-bit increases this ceiling to 16 Exabytes!

Limit: 4 GB vs 17 Billion GB

Why this translates directly to real-world speed:

When doing encryption (AES/RSA), 3D games with 64-bit floating point matrix math, audio processing, or working with large numbers, a 32-bit CPU has to issue multiple instructions and stitch the pieces together, taking 2× or more clock cycles. A 64-bit CPU swallows the whole chunk in one gulp.

Did you know? In a 32-bit Windows system with 4GB of installed RAM, you often only saw ~3.25 GB available. Why? Because the addresses for GPU VRAM, PCI devices, and hardware firmware had to be mapped into that same 4GB address space, eating into physical memory! 64-bit solved this bottleneck permanently.
