Instruction: ADD R1, R2

Tracing how the CPU executes an addition operation of two register contents: Register R1 = 10 and Register R2 = 20, producing 30.

Register R1 10 Operand 1
Register R2 20 Operand 2
ALU Output 10 + 20 = 30 Sum Computation
Program Counter 0x0100 Next: 0x0101
STEP 1 OF 10
FETCH PHASE Program Counter (PC) holds instruction address 0x0100.
PC = 0x0100 points to memory location storing "ADD R1, R2"
1 FETCH RAM → CPU (IR)

Fetch opcode from Memory address held in PC into Instruction Register.

MAR ← PC; IR ← M[MAR]; PC++
2 DECODE Control Unit

Control Unit decodes opcode ADD and identifies operand registers R1 and R2.

CU signals: Read R1, R2; Prepare ALU
3 EXECUTE ALU Computation

ALU computes arithmetic addition: 10 + 20 = 30 with status flag generation.

ALU_OUT ← R1 + R2 (10 + 20 = 30)
4 STORE / WRITEBACK Registers / Output

Result 30 written to target register R1 & forwarded to output monitor.

R1 ← 30; OutputBuffer ← 30

Detailed 10-Step Visual Sequence: ADD R1, R2

Click any step card below to jump to that moment
STEP 01 FETCH
PC Holds Address

Program Counter (PC) stores 0x0100, pointing to the next instruction in RAM.

PC = 0x0100
STEP 02 ADDRESS BUS
Send Address via Bus

CPU sends 0x0100 through Address Bus to RAM, accompanied by a MEMORY_READ signal.

AddrBus ← 0x0100
STEP 03 DATA BUS
RAM Sends Instruction

RAM retrieves instruction ADD R1, R2 from cell 0x0100 and places it on Data Bus.

DataBus ← ADD R1, R2
STEP 04 FETCH COMPLETE
Loaded into IR

Instruction arrives at CPU and is loaded into the Instruction Register (IR) for processing.

IR ← "ADD R1, R2"
STEP 05 DECODE
CU Decodes Opcode

Control Unit decodes ADD opcode. It identifies operation: addition of registers R1 and R2.

CU: Operation = ADD
STEP 06 OPERAND FETCH
Registers Provide Data

Register File outputs R1 = 10 and R2 = 20 to ALU input latches.

ALU_A=10, ALU_B=20
STEP 07 EXECUTE
ALU Computes 10 + 20

ALU adder circuit executes addition: 10 + 20 = 30 and sets status flags.

ALU Result = 30
STEP 08 STORE / WRITE
Result Stored in R1

Output value 30 is written back into destination register R1 (or accumulator).

R1 ← 30 (Updated)
STEP 09 OUTPUT
Display to Output

CPU sends the computed result via I/O bus to Output Device (Monitor/Screen) showing 30.

Output: 30
STEP 10 NEXT CYCLE
PC Incremented (PC+1)

Program counter increments to 0x0101. Cycle starts over for the next instruction.

PC ← 0x0101

Exam Quick-Revision Cheat Sheet — Fundamental Component Roles

Standard definitions and mnemonics required for Computer Organization & Architecture examinations.

CENTRAL PROCESSING UNIT 🧠
CPU = "Brain of Computer"

The core primary hardware unit containing CU, Registers, and ALU that sequentially fetches, decodes, and executes software instructions.

Speed: GHz (Gigahertz) | Clock cycles
CONTROL UNIT (CU) 👔
CU = "The Manager"

Controls and coordinates all operations within the CPU, Memory, and I/O. Decodes opcodes and issues micro-control timing signals.

Hardwired or Microprogrammed logic
REGISTERS ⚡
Registers = "Fast Temporary Storage"

Smallest, fastest memory located directly inside the CPU core. Operates at CPU clock speed with zero wait states (PC, IR, MAR, MDR, General Regs).

Access latency: < 1 nanosecond
ALU 🧮
ALU = "The Calculator"

Carries out arithmetic operations (Addition, Subtraction, Multiplication) and boolean logic evaluations (AND, OR, XOR, Inversion, Shift).

Outputs condition flags: Zero, Carry, Sign
PRIMARY MEMORY (RAM) 📦
Memory = "Stores Data & Code"

Stores active programs and currently running data instructions with linearly addressable byte locations (Volatile DRAM).

Addressed by MAR, transfers via MDR
SYSTEM BUS 🛣️
Bus = "Communication Highway"

Shared physical transmission lines: Address Bus (where to look), Data Bus (what to read/write), Control Bus (how/when to act).

Address (Uni) | Data & Ctrl (Bi)
INPUT DEVICE ⌨️
Input = "Sends Data In"

Translates human-readable commands or sensor signals into binary machine code and stores them into RAM via I/O interfaces.

Keyboard, Mouse, Network Port, Disk
OUTPUT DEVICE 🖥️
Output = "Shows Result"

Converts processed binary bits from CPU/Memory into human-perceptible visual, audio, or persistent physical form.

Display, Audio speaker, Printer

Bus Architecture Comparison Matrix (High-Yield COA Topic)

Bus Type Direction Function / Payload In Our Example (ADD R1, R2) Key Metric
Address Bus Unidirectional (CPU → RAM / I/O) Carries binary memory addresses indicating which cell to read or write. Transmits 0x0100 to RAM Width determines Max RAM capacity ($2^N$)
Data Bus Bidirectional (CPU ⇄ RAM ⇄ I/O) Carries actual instructions, variables, and numerical computed operands. Transfers instruction word "ADD R1, R2" to IR Width determines Word Size (32-bit / 64-bit)
Control Bus Bidirectional (Individual dedicated lines) Carries read/write strobes, clock signals, interrupts, and bus acknowledgements. Sends MEM_READ = 1, then enables ALU latch Controls synchronization & bus arbitration
